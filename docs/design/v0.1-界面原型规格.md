## 1. 设计基调（来自 PRD §4 / §5）

| 维度 | 约束 |
| --- | --- |
| 安静是默认状态 | 菜单栏图标是唯一常驻视觉元素；不出现"系统在看着你"的压迫感 |
| 语气 | 像一位懂分寸的同事，不像监工 |
| 文案 | 不出现"你又没休息""你应该……"等指责句式 |
| 交互 | 任何提醒都能 Skip / Snooze，一键完成 |
| 可解释 | 提醒卡片上永远能找到"为什么" |
| 视觉 | macOS 原生感、毛玻璃、克制留白；主色取"水/青"系冷色 |

## 3. 各页面规格

### P0 设计封面 / 五层干预体系总览

- 左：Tacet 标志 + 定位语「此刻，我知道该我安静了」
- 右：五层干预表（Level 0 Silent / 1 Ambient / 2 Notification / 3 Floating Card / 4 Full Screen / 5 Escalated）
- 标注 v0.1 交付范围：Level 0/1/2/4（Level 3、5 属 v0.2）

### P1 菜单栏下拉主面板（约 360 × 520）

```text
┌──────────────────────────────────┐
│ 🎵 Tacet            连续工作 1h32m │  ← 状态头（Working）
├──────────────────────────────────┤
│ ┌────────────┐ ┌────────────┐    │
│ │ ☕ 休息      │ │ 💧 喝水     │    │  ← 四类健康状态卡
│ │ 距提醒 18m  │ │ 距提醒 12m  │    │     每卡：图标 / 名称 / 倒计时
│ └────────────┘ └────────────┘    │
│ ┌────────────┐ ┌────────────┐    │
│ │ 🧍 活动      │ │ 👁 护眼     │    │
│ │ 距提醒 42m  │ │ 已达标 ✓    │    │
│ └────────────┘ └────────────┘    │
├──────────────────────────────────┤
│ [ 现在休息 ]   [ +1 杯水 ]        │  ← 快捷操作
│ [ 活动打卡 ]                      │
├──────────────────────────────────┤
│ ⚙ 设置      ⏸ 暂停计时     退出   │  ← 底部
└──────────────────────────────────┘
```

要点：暂停计时为 v0.2（F1.5，P2），原型中可作为灰态占位或标注。

### P2 菜单栏状态变体（Level 1 Ambient）

菜单栏右侧图标 + 文本的 4 种状态：

| 状态 | 表现 | 触发 |
| --- | --- | --- |
| 静默（默认） | 仅图标 | 需求低 / 刚休息完 |
| 工作计时 | 🎵 1h 32m | Working 中 |
| 喝水临近 | 💧 12m | 某需求接近阈值 |
| 勿扰 | 图标变暗 + 斜线 | 用户手动开启勿扰 |

约束：不发声、不弹窗。

### P3 Level 2 系统通知

macOS 通知横幅样式，含操作按钮：

```text
┌────────────────────────────────────────┐
│ Tacet                            现在   │
│ 建议休息一下                            │
│ 你已经连续工作 78 分钟了。              │
│ [ 现在休息 ]  [ 3 分钟后 ]              │
└────────────────────────────────────────┘
```

喝水场景变体：

```text
│ 如果方便，记得喝点水                    │
│ [ 已喝水 ]  [ 稍后 ]                    │
```

约束：通知文案必须包含"稍后"选项（PRD §3.3）。

### P4 Level 4 全屏 Overlay（休息提醒）

毛玻璃全屏覆盖（单显示器，v0.1）：

```text
┌──────────────────────────────────────────────────────────┐
│                                                          │
│                    建议休息一下                            │
│                                                          │
│                       05:00                              │  ← 休息倒计时
│                                                          │
│   ──────────────────────────────────────────────         │
│   为什么现在提醒我：                                       │
│   ✓ 已连续工作 78 分钟                                    │
│   ✓ 未检测到会议                                          │
│   ✓ 上次休息 2 小时前                                     │
│   ──────────────────────────────────────────────         │
│                                                          │
│   [ 现在休息 ]  [ 延后 1 分钟 ] [ 3 分钟 ] [ 5 分钟 ]      │
│                  跳过                                     │
└──────────────────────────────────────────────────────────┘
```

硬约束：
- **永不**锁屏
- 必须提供 Skip
- 不得阻塞系统快捷键（cmd+tab、输入法切换）
- 不得遮挡 5 秒以上无法关闭

### P5 Intent 记录

进入休息模式前的单行输入：

```text
┌──────────────────────────────────────────┐
│  休息前，记一下接下来要做什么？            │
│  ┌────────────────────────────────────┐  │
│  │ 完成 Auth 模块测试                  │  │  ← 单行文本，≤100 字符
│  └────────────────────────────────────┘  │
│  休息结束时会原样还给你                    │
│              [ 跳过 ]   [ 保存并休息 ]    │
└──────────────────────────────────────────┘
```

### P7 休息结束 + Intent 恢复

```text
┌──────────────────────────────────────────┐
│              欢迎回来                      │
│                                          │
│   休息前你准备继续：                       │
│   ┌────────────────────────────────┐     │
│   │ 完成 Auth 模块测试              │     │
│   └────────────────────────────────┘     │
│                                          │
│   本次休息 5 分钟 · 活动打卡 ✓             │
│                                          │
│              [ 开始 ]                     │
└──────────────────────────────────────────┘
```

约束：Intent 呈现/恢复优先级高于视觉花哨（PRD §4.6）。

### P8 设置页

```text
┌──────────────────────────────────────────────────┐
│  设置                                             │
├──────────────────────────────────────────────────┤
│  提醒                                             │
│  ┌──────────────────────────────────────────┐    │
│  │ ☕ 休息提醒    [开关]    间隔 [50] 分钟    │    │
│  │ 💧 喝水提醒    [开关]    间隔 [45] 分钟    │    │
│  │ 🧍 活动提醒    [开关]    间隔 [60] 分钟    │    │
│  │ 👁 护眼提醒    [开关]    间隔 [40] 分钟    │    │
│  └──────────────────────────────────────────┘    │
│                                                   │
│  勿扰                                             │
│  ┌──────────────────────────────────────────┐    │
│  │ 勿扰模式        [开关]                    │    │
│  │ 仅在工作时间提醒  [开关]（v0.2）           │    │
│  └──────────────────────────────────────────┘    │
│                                                   │
│  通用                                             │
│  ┌──────────────────────────────────────────┐    │
│  │ 开机自动启动     [开关]                    │    │
│  │ 关于 Tacet       v0.1.0  ›                │    │
│  └──────────────────────────────────────────┘    │
│                                                   │
│  AI 助手（可选）                            ›     │  ← 静默入口，不弹窗、不催促
└──────────────────────────────────────────────────┘
```

硬约束（原则 7 / F8.8）：未配置 AI 时，此入口**静默存在**，无红点、无提示、不阻塞任何流程。

默认间隔来自 PRD §3.2：休息 50 / 喝水 45 / 活动 60 / 护眼 40 分钟。
