## 设计基调（来自 PRD §4 / §5）

- **安静是默认状态**：菜单栏图标是唯一常驻视觉元素
- **主色**：青蓝 `#2FA8A0`（水感冷色）；语义色 —— 休息=青、喝水=天蓝 `#4A9FE0`、活动=暖橙 `#DE8B41`、护眼=柔紫 `#8B7BD8`、达标=柔绿 `#4CAF7D`
- **语气**：像一位懂分寸的同事；文案中不出现任何指责句式
- **可解释**：Level 4 Overlay 上永远能看到「为什么现在提醒我」的因子清单

### 三条硬约束在原型中的体现

| 约束 | 体现在 |
| --- | --- |
| 永不锁屏 / 随时可跳过 | 04 页底部：「永不锁屏 · 随时可以关闭 · 不阻塞 ⌘Tab 与输入法切换」+「跳过这次提醒」 |
| 通知必须含「稍后」 | 03 页两张通知都带次要按钮（3 分钟后 / 稍后） |
| AI 完全可选 | 08 页「AI 助手（可选）」在设置页最底部，灰字、无红点、无提示 |

## 重新生成

原型由脚本手写生成（每一页的布局、间距、颜色、图标均在脚本中显式写出，无模板套用）：

```bash
cd docs/design/prototype-v0.1
python3 _build.py     # 会覆盖同目录下的 01~08 页面
```

> 注：`_build.py` 的输出路径为脚本所在目录，生成后需按「页面清单」核对文件名。

> 当前账号默认个人空间没有可用的任务。请先在墨刀 AI 对话一次，或显式提供当前账号已有的 task_id/task_url。
