# Tacet 品牌资产

本目录存放 Tacet 的视觉识别资产：Logo、应用图标、菜单栏图标，以及
**它们为什么长成这样**的设计依据。

> 设计稿的迭代过程全部保留在本目录（`candidate-*.png` / `v2-*.png` /
> `v3-*.png`）。这些「废案」不是垃圾 —— 它们记录了每一次判断的转变，
> 是将来回顾「为什么最终选了这个方向」时唯一的证据。

---

## 一、这个名字本身就是设计

**tacet** 是乐谱记号，意思是「此处休止」。

它的含义不是「退出」，也不是「不重要」，而是：

> **此刻，我知道该我安静了。**

这给了一个罕见的优势：**产品名、产品哲学、视觉符号可以是同一件事**。
大多数品牌要花很大力气才能把名字和图形挂上钩，而 Tacet 天然就有一条路：

```
tacet（休止）→ 停下来的时刻 → 休息 → 健康
```

所以视觉设计的核心任务只有一句话：**把「安静」画出来，并且让它显得温柔。**

## 二、调研：同类产品在怎么做

设计之前先看了真实的对标，不靠想象。

| 产品 | 图形 | 字 | 关键结论 |
| --- | --- | --- | --- |
| **Headspace** | 一个橙色实心圆 | 小写粗体无衬线 | 图形简单到极致，**性格全部由颜色和字体承担** |
| **Calm** | 没有图形，只有手写体单词 | 手写体小写 | 连图形都不要，**靠「手写感」传递人性化** |

两者都是全球最大的冥想 App。它们的共同点是：

1. **图形极简**，甚至没有图形
2. **但绝不冷** —— 一个用暖橙色，一个用手写曲线
3. 都避免了「精密仪器感」，都在说「我是你的朋友」

**这直接否定了一个常见误解**：以为「高级」=「极简 + 冷色 + 几何精度」。
Headspace 和 Calm 证明了「高级」的真正来源是**克制 + 温度**，而不是冰冷。

### 一个技术性的教训

AI 生图模型**不擅长**画干净的极简矢量图 —— 它擅长的是质感、光影、层次。

我第一版提示词里写满了 `no gradient, no shadow, no depth`，
把模型擅长的东西全部禁掉，只留下一根光秃秃的线，结果既不矢量也不好看。

**正确做法**：让模型做它擅长的事（材质、光、渐变、层次），
而需要像素级精确的部分（菜单栏图标）改用代码绘制。

## 三、色彩

| 名称 | 十六进制 | 用途 |
| --- | --- | --- |
| 主青绿 Deep Teal | `#0C6E66` | 品牌主色，界面主色（`--brand`） |
| 深夜青 Midnight | `#052A2E` | 深色底、应用图标背景 |
| 发光青 Luminous | `#2FD8C4` | 高光、发光元素 |
| 暖琥珀 Amber | `#F0A44A` | **唯一的暖色**，点睛用 |
| 暖白 Warm White | `#F7F5F2` | 浅色底 |

### 为什么需要一个暖色

纯青绿的健康产品会显得像医疗器械。那一点点琥珀色是整个方案里
最重要的一个决定 —— 它让 Tacet 像「一位懂分寸的同事」，
而不是「一台监测仪」。这与 PRD §5 的语气规范是同一件事的两种表达。

## 四、菜单栏图标

### 必须在 22pt 下成立

菜单栏图标和 App 图标是**两种不同的设计**，不能用同一张图缩放。
菜单栏图标的硬性约束：

1. **纯单色 + 透明背景**。macOS 把它当「模板图像」自动反色 ——
   浅色模式显示为黑，深色模式显示为白。任何彩色或渐变都会让这个
   机制失效。
2. **22pt 下清晰**。这个尺寸下只有「形状」有效，细节全部消失。
3. **边缘必须像素级精确**。AI 生图的抗锯齿噪点在 22pt 下会变成一圈灰边。

所以菜单栏图标用代码绘制：见
[`apps/desktop/icons/generate_tray_icons.py`](../../apps/desktop/icons/generate_tray_icons.py)。

### 三个候选

| 候选 | 形状 | 概念 |
| --- | --- | --- |
| **A 断线** | 一条横线中间有断口 | 工作流被一个有意的停顿切开 |
| **B 圆环** | 留缺口的圆环 | 工作与休息的循环，缺口就是那次呼吸 |
| **C 休止符** | 长短两道横杠 | tacet 的字面含义；也呼应菜单栏本身那条横线 |

### 尺寸体系（一个踩过的坑）

这里有三套单位，极易混淆：

| 单位 | 含义 | 换算 |
| --- | --- | --- |
| `pt` | 设计尺寸（菜单栏里看到的） | 1pt = 2px |
| `px` | 44px 成品图里的像素 | 1px = 4u |
| `u` | 超采样画布单位 | 1u = 1/8 pt |

我第一版把「超采样倍数 4」当成了「pt → 画布单位」的换算，
导致所有笔画只有应有粗细的**一半**，图标在菜单栏里细得像头发丝。
现在统一用脚本里的 `u()` 函数换算。

## 五、应用图标

应用图标遵循 macOS Big Sur 之后的规格：

- **圆角方形（squircle），铺满整个画布，四周不留白边**
- 尺寸阶梯：16 / 32 / 64 / 128 / 256 / 512 / 1024 px
- 深色模式下有自己的版本（`v3-midnight` 天然适合）

当前三个方向（见 `v3-*.png`）：

| 方向 | 描述 |
| --- | --- |
| **lens** | 深青毛玻璃球，内部一道发光的横线 |
| **aurora** | 青绿渐变的立体圆环，留一个缺口 |
| **midnight** | 深色底 + 两道发光横杠（休止符）+ 暖琥珀光晕 |

### 迭代过程的三个阶段

| 版本 | 做法 | 结果 |
| --- | --- | --- |
| v1（candidate-01 / concept-a-line） | 把 logo 写成**施工图纸**（「一根细矩形 + 一根粗矩形，比例为 40%」） | 丑。模型只能当描图员，做出来像个锤子或进度条 |
| v2（v2-\*） | 改为描述**概念关系**，放开质感与光 | 质感对了，但图标四周留白，不符合 macOS 规格 |
| v3（v3-\*） | 加上「铺满画布」等平台规格约束 | 可用的正式候选 |

**核心教训**（写下来避免重犯）：

1. 好的 logo 提示词给的是**一个概念关系**，不是一套尺寸标注。
2. AI 生图擅长**质感与光**，不擅长**干净的矢量**。别把它当 Illustrator 用。
3. 「高级」不等于「极简 + 冷色」。Headspace 用暖橙、Calm 用手写体 ——
   真正的来源是**克制 + 温度**。
