# 同类项目调研（v0.3 前置）

> 调研日期：2026-10-10。信息来自各项目的 README / 官网原文，**会随它们的版本变化**，引用前请以当前官方页面为准。
> 目的：为 v0.3「更懂时机」选定要吸收的设计，并明确哪些东西 Tacet **不做**。

## 1. 调研对象与结论摘要

| 项目 | 形态 | 值得吸收 | 不吸收 |
| --- | --- | --- | --- |
| [Stretchly](https://github.com/hovancik/stretchly) | Electron，跨平台，开源 | ① 监听系统「勿扰」，勿扰时暂停休息；② 空闲 5 分钟视为自然休息，计时暂停；③ 休息前预告（Mini 休息提前 10 秒、Long 休息提前 30 秒通知）；④ 先延后一次，之后才允许跳过的「阶梯」 | 严格模式（strict mode，强制不让跳过）——与 Tacet「永不强制锁屏」冲突 |
| [Safe Eyes](https://github.com/slgobinath/SafeEyes) | Python/GTK，Linux | ① Smart pause（空闲时暂停）；② 多屏支持；③ 命令行控制运行中实例；④ 插件化 | 休息期间禁用键盘（Disable keyboard during breaks）——同样属于强制 |
| [Workrave](https://github.com/rcaelers/workrave) | C++，Linux/Windows，GPL | ① 微休息 / 休息 / 每日用量上限三层节奏；② 统计里区分「做了」「忽略」「推迟」三种结果 | 「每日电脑使用上限、到点提示停止使用」——是惩罚性的叙事，Tacet 不做 |
| [LookAway](https://lookaway.com)（商业，闭源，仅看官网文案） | macOS 原生 | ① **会议 / 通话期间自动暂停**；② 深度专注类 App 期间暂停；③ Planned Breaks（固定时间的休息，如午休）；④ 与系统专注模式联动 | 闭源，无法参考实现，只参考产品行为 |

## 2. Tacet 与它们的差距（调研前的盘点）

| 能力 | Stretchly / LookAway | Tacet v0.2.4 |
| --- | --- | --- |
| 会议中不弹全屏提醒 | LookAway 有；Stretchly 靠系统勿扰间接做到 | **没有**：开会时到点照样盖全屏 |
| 定时勿扰（30 分钟 / 1 小时 / 到明早） | Stretchly 有「暂停 N 分钟」类菜单 | 只有一个无期限开关，**容易忘了关，之后永远没有提醒** |
| 只在工作时段提醒 | LookAway 有计划能力 | 没有：深夜、周末照样提醒 |
| 每日喝水目标与进度 | — | 只有「次数」，没有目标 |
| 连续延后后的温和变化 | Stretchly 的「先延后、再跳过」阶梯 | 已有延后阶梯（5→15→30→60），但文案没有任何变化 |

## 3. v0.3 的取舍（决策）

1. **会议感知**：采用「麦克风占用」这一个信号（Stretchly 没有，LookAway 有）。**不读日历、不录音、不申请权限。**
2. **定时勿扰**：吸收 Stretchly / LookAway 的思路，但落点做成「到点**自动恢复**」，从根上避免忘关。
3. **工作时段**：时段外保持安静；**默认关闭**，不替用户假设他的作息。
4. **喝水目标**：只展示进度，不催促、不惩罚。
5. **连续延后的文案**：只换文案，不换功能；绝不吸收 Stretchly 的 strict mode 与 Safe Eyes 的禁用键盘。
6. **本轮不做**：Planned Breaks（固定时间休息）、与系统专注模式联动、命令行控制——已记入路线图候选，见文档中心《版本路线图》。
