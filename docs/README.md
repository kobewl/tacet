# 工程文档（随代码走）

本目录存放**随代码演进**的工程文档，例如：

- 具体模块设计与实现说明（如平台抽象层的实现细节）
- IPC 接口契约（Rust ↔ 前端命令清单）
- 技术 Spike 结论（Overlay 验证、麦克风检测验证等）
- 开发环境搭建与排障记录

> **产品与项目文档**（路线图、功能清单、PRD、架构规划、数据模型、研发规范、发布流程、决策记录）
> 统一存放于本地文档中心：`~/Documents/Project Documentation/Tacet-文档`
>
> 两处分工：
> - `Tacet-文档/` —— 规划级、跨版本长期有效的文档（相对稳定）
> - `docs/`（本目录）—— 实现级、随代码细节变化的文档（跟随代码走）
