# 图标资产

Tacet 有两套完全不同的图标，它们的**技术要求不同，不能用同一张图缩放**。

---

## 1. 应用图标（Dock / Launchpad / Cmd+Tab）

| 文件 | 说明 |
| --- | --- |
| `icon.icns` | macOS 原生图标（1024px，含完整尺寸阶梯） |
| `icon.png` | 512px PNG（部分场景使用） |
| `icon-lens.icns` / `.png` | 候选 ①「玻璃球」 |
| `icon-aurora.icns` / `.png` | 候选 ②「极光环」 |
| `icon-midnight.icns` / `.png` | 候选 ③「深夜琥珀」**（当前默认）** |

### 切换候选

```bash
./switch_icon.sh midnight    # 深夜琥珀（当前）
./switch_icon.sh lens        # 玻璃球
./switch_icon.sh aurora      # 极光环
```

切换后需要重新构建才生效。

### 三个候选的实测差异（选型依据）

| 尺寸 | ① 玻璃球 | ② 极光环 | ③ 深夜琥珀 |
| --- | --- | --- | --- |
| 128px（Dock） | 好看 | 好看 | 好看 |
| 64px | 好 | 好 | 好 |
| **16px** | **变成「禁止」符号** | 变成 C / 转圈 | **糊成一团** |

- **① 在 16px 下是「圆圈 + 横杠」，即国际通行的禁止符号** ——
  对健康产品是语义错误，所以它不能做默认。
- **③ 在 16px 下会糊**（深色底 + 细小发光元素缩小后糊在一起），
  但 16px 只出现在 Finder 列表视图和「显示简介」里，影响面小。
- **② 缩放性最好**，但小尺寸下容易被认成「加载中」。

**当前选 ③ 的理由**：它的概念最强（就是乐谱的休止符，与产品名同源），
而它退化的那个尺寸恰恰是用户最少看到的那个。

## 2. 菜单栏图标（托盘）

| 文件 | 说明 |
| --- | --- |
| `tray.png` | **当前使用**：休止符方向（44px @2x = 22pt） |
| `tray-a-broken-line.png` | 候选 A：断线 |
| `tray-b-open-ring.png` | 候选 B：留缺口的环 |
| `tray-c-rest-sign.png` | 候选 C：休止符 |
| `generate_tray_icons.py` | 生成脚本 |

### 重新生成

```bash
python3 generate_tray_icons.py
```

### 为什么必须用代码画，不能用 AI 生图

1. **必须纯单色 + 透明背景**。macOS 把它当「模板图像」自动反色 ——
   浅色模式显示为黑，深色模式显示为白。任何彩色都会让这个机制失效。
2. **必须在 22pt 下清晰**。这个尺寸下只有「形状」有效。
3. **边缘必须像素级精确**。AI 生图的抗锯齿噪点在 22pt 下会变成一圈灰边。

脚本里有一处 `assert` 会校验缺口角度在合理范围（25°~55°），
防止有人改了参数之后缺口变得看不出或不成环。

### 三套单位（一个踩过的坑）

| 单位 | 含义 | 换算 |
| --- | --- | --- |
| `pt` | 设计尺寸（菜单栏里看到的） | 1pt = 2px |
| `px` | 44px 成品图里的像素 | 1px = 4u |
| `u` | 超采样画布单位 | 1u = 1/8 pt |

第一版把「超采样倍数 4」误当成了「pt → 画布单位」的换算，
导致所有笔画只有应有粗细的**一半**，图标在菜单栏里细得像头发丝。
现在统一用脚本里的 `u()` 函数换算，不要再手写乘数。
